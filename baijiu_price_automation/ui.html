开始一次行情更新

  1. 点击“导入自己的数据库”，上传同格式 XLSX；也可默认接续最新版本。上传文件另存副本并检查模板。选择需要更新的日期范围，一次最多 32 天。
  2. 微信历史采集：先登录 Windows 微信，打开搜一搜；采集期间保持桌面解锁，暂停鼠标和键盘操作。
  3. 已有原文链接：选择链接解析，逐行粘贴文章地址。微信读书通道需授权，只返回最新文章，历史补抓依赖公开合集。
  4. 完成后下载 Excel，并检查未取得报价与图片识别复核记录。

公众号未公布某品类属于正常缺失。工具不会补造报价；15 天和 1 月前的快照随历史积累生成。
