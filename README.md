# 酒价观测

微信公众号行情 → 文字与图片识别 → 按模板更新 Excel。

面向研究工作中的每日酒价维护，支持茅台、五粮液、泸州老窖与习酒的 14 个品类，按 6 个公众号分别保存报价，更新品牌页和总表，并计算当日渠道均价。

## 开始使用

1. 在 Windows 电脑安装 Python 3.11 或 3.12，下载并解压仓库。
2. 双击 `首次安装.bat`，联网安装依赖。
3. 双击 `启动工具.bat`，浏览器打开 `http://127.0.0.1:8765/`。
4. 点击「导入自己的数据库」，上传同格式 XLSX，包含「更新手册、茅台、五粮液、泸州老窖、习酒、Sheet1」。上传后会核验表头与渠道，另存副本；请自行准备有权使用的模板和历史数据。
5. 选择日期和采集方式，完成后查看品牌报价、复核记录并下载 Excel。

首次使用需要准备自己的数据库。本仓库不包含开发者数据库、微信登录、Cookie、API Key 或采集缓存。详见 [分享使用说明](分享使用说明.md)。

## 三种采集方式

| 方式 | 如何取得文章 | 使用条件 |
| --- | --- | --- |
| 微信历史采集 | 复用微信桌面 RPA 搜一搜、公众号历史文章与原文链接校验 | Windows 微信已登录，桌面解锁；运行时暂停鼠标键盘操作 |
| 原文链接解析 | 读取指定微信原文，保留正文、HTML 表格与图片，运行本地 OCR | 能访问原文；此模式不操作微信桌面 |
| 微信读书 | 外接 WeRSS 服务，读取最新文章并尝试公开合集补抓 | 需单独部署、授权；本包不包含该服务，不能保证历史覆盖 |

还支持导入 TXT/HTML/CSV 文章、试运行。首次安装后正常更新由本地 Python 程序运行，默认使用本地 RapidOCR，无需大模型 API 或按次购买 Token。

## 数据规则

- 覆盖茅台、五粮液、泸州老窖、习酒，网页显示各品牌确认报价并可筛选。
- 公众号、发布时间、标题日期与今日价格列须通过核验；失败留下复核记录。
- 保留年份、度数、容量与包装差异：25 年飞天不能混入 26 年；窖藏1988按正装统计，排除雅致版。
- 长图低置信度产品行会按原始分辨率局部重识别；重试须达到 0.92 且数字一致，无法确认时保持空白。
- 原模板未配置的渠道与品类不列入预期报价；没有公布价格是正常缺失，不填 0，不复制昨天价格。
- 名称对照表同步到 Excel「更新手册」。更新后筛选范围和打开位置随实际报价更新。
- 每次更新另存文件；显示最新、上次、15 天前与 1 个月前的四个检查点。其余旧版本可恢复，历史不足时显示无快照。

## 实现与目录

`wechat-article-rpa/` 复用 [Dhaizei/wechat-article-rpa](https://github.com/Dhaizei/wechat-article-rpa) 的采集和原文处理，扩展结构化表格、图片 OCR、行情核验与证据归档。

`baijiu_price_automation/` 提供本机网页、数据库导入、模板匹配、Excel 写入、均价与版本管理。

采集原文 → 核验账号与日期 → HTML 表格直接解析 / 图片下载与 OCR → 对齐当前价格列 → 映射模板酒款和公众号 → 写入四个品牌页与 Sheet1 → 复核、另存、归档。

## GitHub 和网站部署

GitHub 分享：直接分享本仓库，使用者下载后在自己的 Windows 电脑安装，登录自己的微信并上传自己的数据库。

GitHub Pages：只能展示 HTML/CSS/JS 等静态内容，无法运行此工具的 Python 后端。参见 [GitHub Pages 官方说明](https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages)。

完整网站：需要 Python 后端、文件存储、上传校验、登录权限和任务队列。当前服务按单人本机使用设计，监听回环地址，尚未实现公网身份认证或用户隔离。不要把本地服务直接开放到公网。

云端可以承担原文链接解析与数据库更新；桌面 RPA 需要已登录微信的交互式 Windows 环境，可保留在用户电脑，通过受控的本地采集端与网站连接。普通静态托管或 Linux 云服务无法直接操作用户电脑上的微信。
